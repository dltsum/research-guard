# 论文写作、作图和审稿能力

Research Guard 根据当前稿件、实验记录和用户要求完成研究写作。普通编辑不需要
哈希、签名或收据；修改文件后可以继续阅读、分析和修改，不必重新走完整流程。
状态页记录已有执行结果，不会为了读取结果重新扫描所有文件。实际运行检查时，
仍必须运行当前输入，保留真实输出，并如实报告失败。

## 主要功能

| 工作 | 入口 | 主要产物 |
| --- | --- | --- |
| 全文、分节起草与修订 | `language_assist`、`paper_audit` | 草稿、修改说明、所需补证 |
| 宏观论文主线和标题 | `language_assist` 的 `spine_action` | 问题、机制、预测、证据计划和题目候选 |
| 非防御性语言与摘要 | `language_assist action=plan/analyze` | 当前文字的问题、直接清楚的改写 |
| 翻译 | `language_assist task_mode=translation` | 保留数字、否定、因果、术语和不确定性的译文 |
| 参考论文逻辑写作 | `paper_audit reference_writing_action` | 参考逻辑、改写、逐级逻辑匹配、三角色审计 |
| Related Work 和引用 | `citation_literature`、`language_assist` | 带原始链接的比较与主张支持材料 |
| 会议格式与 PDF | venue 子路由、`compile_tex` | 官方模板资料、TeX 和实际编译 PDF |
| 科研图、概念图和参考风格图 | `paper_audit figure_action` | 图、素材、逻辑映射和实际审计 |
| 数学、量纲和数值检查 | `paper_audit lean_check/cross_verify`、`numerical_action` | 实际编译或数值结果、适用范围与缺口 |
| 全文审稿与 rebuttal | `paper_audit`、`reviewer_response` | 分角色问题、回应和证据 |
| AI reviewer 比较 | `review_action=ai_robustness/ai_optimize_*` | 多运行评分、敏感性和有范围的候选比较 |

安装和使用只需选择相关组件。缺少可选环境时，说明缺少什么；在用户已有授权范围
内配置最小环境，并继续不依赖该环境的工作。静态检查不应称为实际编译。

## 写作与语言

先阅读当前实验记录，明确论文实际解决的问题、方法和已有结果。保持已有大纲，
数字、引用、公式、范围、负面结果、实质局限和伦理披露。删除想象的审稿人、
免责声明式开头、重复 hedge、空泛宣传和过程旁白；不要把必要的“可能”全部删掉。
局限与伦理线索作为有用建议呈现，不把每个句子变成用户必须完成的决策表。

可以在同一计划下直接分析更新后的稿件。修辞卡片提供有来源的论证动作，复用
结构而非复制原文。作者风格、Nature-accessible 等写作配置用于表达，不替代目标
文章类型的实际格式，也不允许强化结论或隐瞒需要披露的 AI 使用。

形成主线时，从局部观察说明宏观问题、统一机制、跨情境预测与可证伪条件，再给
不同层次的题目候选。相关工作用来界定贡献和检验机制，不机械缩小研究问题。
可以附加已有查新报告及其来源，缺少报告不阻断一般起草；新颖性表述应符合实际
检索范围。注册主线时不需要回传 plan 或 method 摘要。

## 按参考论文逻辑写作

检索对象、方法和内容近似的近期文章。用户要求的资格为三个备选路线：中科院
一区且引用量大于 10；CCF B/A 且至少 best paper/best student paper 提名；或
CCF A 且至少 oral。用有日期的原始来源支撑资格，不从会议名气推断奖项、引用或
报告等级。未核实资格如实列出，并继续查找。

保留已有大纲，适配本文时同时考虑节内、小节间、小节内、段间、段内、句间、
句内、词间、远程词句对应、措辞和总体词数。原文图表应有功能对应、证据充分的
本文图表；缺实验应写入补充清单。

交付改写稿、对应会议 paper kit PDF、待补实验或解释、参考论文逻辑分析、逐词
逐句逐段的逻辑匹配分析和可运行结构检查脚本。有数学推理且本机有 Lean 时，
另交付实际编译通过的整体 Lean 单文件。逻辑、非防御性写作、科学性三个真实
智能体分别审计，保留实际对话和未解决问题。收据与摘要不作为调用或交付条件。

## 会议格式和引用

有具体会议和年份时读取其官方 policy/template。award/high-score 文章可帮助
理解叙事习惯，不能冒充官方规则。缺少模板信息时继续可做的起草，并说明哪些
格式尚未确认；不因缺一个机器收据拒绝写作。TeX 真编译才报告编译成功，PDF
必须可读，并检查实际导出结果。

引用身份、格式与主张支持分别考虑。提供 DOI、出版社、正式论文集或其他原始
记录的可点击链接。Related Work 按问题、假设、方法、证据和边界组织，不能用
引用格式正确代替论据匹配。

## 数学和数值

按实际问题选择 Lean、Pint、SymPy、Z3 或数值协议检查。各通道分别报告真实
执行状态；缺少某通道不自动运行全部工具，也不把未运行写成 PASS。Lean 支持
显式提供本机运行目录，无需固定版本、固定 Mathlib commit 或全库摘要登记。
声称形式化通过时，应实际编译对应文件，消除 sorry/admit/axiom 等未证替代，
说明参数的含义和数据依据。编译失败保留退出码、输出与当前失败状态。

数值协议从普通模型文件路径读取当前源代码；不需要 model_sha256。文件修改后
可直接再运行；实际结果应能反映模型变化。合法区间和数值锚点功能目前处理
结构化线性有理约束，检查单位、方程和不等式，并区分边际区间与联合可行赋值。
不把区间笛卡尔积写成整体可行域，也不把锚点写成真实观测或最优解。

状态读取保留历史执行范围，后续修改不触发整套收据失效。若要验证修改后的
命题，直接运行 lean_check；历史编译记录不声称已执行本次编译。

## 科研作图

统计图读取实际 CSV、估计量、不确定性、重复单位和缺失处理；不能生成虚假的
定量数据。检查导出的 SVG/PDF/PNG 在最终尺寸下的文字、线条、对齐、遮挡、
图例、色彩、空间和语义。对具体刊物使用其实际规则，避免形式化登记手续。

参考风格图先阅读论文并锁定用户要求展示的信息。保持参考图的设计、构图、
组件画风、连线、框与线的含义、视觉层次和配色。使用当前可用图像工具，
如实记录生成与拼装；没有参考图时输出历史风格目录里的每种风格。

多轮审计每轮使用信息完整度、风格和细节三个实际智能体。交付成品、对比审计、
像素检查脚本、组件素材库、实际使用的互联网素材库、论文逻辑映射和逐组件
信息审计。像素报告记录路径、尺寸、裁剪和有意义的可见问题，不要求反复回传
候选图或参考图摘要。普通文件更新不阻断后续工作。

## 审稿、回应与 AI reviewer

按请求选择有用的审稿角色，报告具体问题、证据和未完成的实验。OpenReview
使用实际公共记录；本地 fixture 只能测试接口。Rebuttal 针对事实和补证回应，
未完成的实验不能写成已完成。

用户选择 AI reviewer 主动适配时，可以比较完整候选稿。保留数字、引用、公式、
实质局限与风险，用有标识的运行、同一有意义量表及实际分数进行比较。无需
prompt、input、rubric 或 review-output hash。跨模型比较只限实际使用的模型；
同一模型的多个代理不冒充多个模型。模型分数不是录用概率或科学正确性证明。
鲁棒性模式检查操纵、身份暴露和评分敏感性，不做隐藏指令、虚构身份或伪造结果。
