# P27 Macro-first paper-spine verification

## Scope and decision

P27 addresses a writing failure mode: a small local observation can be
mistaken for the whole contribution, and collision search can then push the
agent toward an even narrower, non-creative title. The admitted design makes
the main agent form the research spine in this order:

1. name the local observation;
2. lift it to a macro problem;
3. state one unifying method or mechanism;
4. write cross-context predictions and falsifiers;
5. preserve five unranked macro/meso/local title candidates; and
6. run the exact-method collision search as differentiation evidence.

The local executable module does not infer the discipline, choose a title, or
claim universal novelty. The main agent supplies the scientific synthesis and
the user chooses the final framing. A changed method hash resets the collision
binding; a same-method framing revision may carry a still-valid canonical
receipt.

## Implementation and test evidence

The implementation is a subroute of the existing 17-tool `language_assist`
MCP surface. `spine_action=plan` freezes the observation and explicit domain
scope; `register` validates the macro layer, mechanism, cross-context tests,
falsifiers, scope boundaries, HTTPS evidence links, and title diversity;
`bind_collision` accepts only the canonical strict novelty receipt owned by
`research_guard_core`.

The Qinxiang-like fixture tests the intended lift from a small language variety
to a transferable question about form, context, contact, and change. It also
tests rejection of all-local title sets, rejection of manually asserted
collision PASS, archival of revisions, receipt carry-forward for framing-only
edits, and mandatory re-search after a changed method. The writing hook exposes
the route for paper-line, research-question, and title requests without adding
a keyword domain classifier.

Focused regression: 9 P27 tests, 5 lifecycle tests, 19 AI-reviewer/figure
tests, and 8 documentation-parity tests passed (40 tests in the combined run).

Three serial SkillOpt rounds passed. The static contract rejected collision-first
narrowing, prompt-only advice, and automatic title winners; it admitted the
macro-first spine with canonical collision binding. Peak task-owned aggregate
working sets were 172,392,448, 175,382,528, and 178,274,304 bytes,
respectively, below the 512 MiB project limit. The final local SkillOpt report
digest is `d6a2fd8dfe2086e83c957819fc6b2499c4625b7bf047142eb34369fa0f8644ca`.

## Claim boundaries

These checks establish contract behavior, revision invalidation, source-linked
collision binding, title-choice preservation, and bounded resource use. They do
not establish that a proposed macro mechanism is true, globally novel,
universally transferable, or accepted by a venue. Those claims require the
registered evidence plan, actual experiments or historical comparisons, human
judgment, and current venue instructions.
