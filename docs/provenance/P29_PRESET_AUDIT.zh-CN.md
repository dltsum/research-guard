# P29 预设审计实现记录

## 范围

P29 解决发布包继承开发者 home、代理、包索引、运行时、全局 Git 代理、可选学术凭据、工作站字体或主机语言环境的问题。它覆盖完整检出文件，包括已跟踪和被忽略的文件，并在有界 ZIP 与 tar 系列成员内检查 UTF-8 文本，只排除 `.git`。符号链接会作为跳过项显示，不会被静默跟随。

## 实现

仅使用标准库的[预设扫描器](../../scripts/preset_audit.py)读取声明式[策略](../../assets/preset-audit-policy.json)，对证据脱敏，扫描发布归档，并将违规项与有意夹具/证据和可移植回退分开。安装根目录、签名密钥位置、Windows/POSIX 运行时启动器、Git 源传输、学术来源路由回退、可选凭据输入、字体/语言选择以及 pip/uv 子进程环境现在都会先遵守用户显式选择，再使用可移植默认值。所有学术适配器共享同一个路由解析器，复制的检出不会漂移到第二套代理策略。回执还带有路径/平台/语言环境/字体、环境、网络/索引、凭据、子进程、资源、归档/清理和溯源机制台账；示例只保留模式 ID 与位置，不复制匹配值。该路由通过 [`researchctl preset-audit`](../../scripts/researchctl.py) 和已有的 `research_design` 维护面提供，不新增顶层 MCP 工具。

## 验证

定向 P29 测试覆盖完整检出扫描、绝对和转义 Windows 路径、有界 ZIP/tar 检查、生成回执处理、忽略文件范围、MCP 路由、包索引与 Python 主机变量清理、可选凭据分类、显式安装根目录/运行时优先级、签名密钥位置以及 Git 直连行为。仓库校验器和两个包构建器会在接纳源目录或归档前调用同一审计。

## 边界

这不是攻击者或安全审查。二进制/非 UTF-8 文件、符号链接和有界归档成员会计数并列为跳过，其内容不会被断言为可移植。测量的主机事实、用户命令环境继承、刊物证据和 localhost 控制台绑定都是可见分类，而不是隐藏例外。回执中不放置源文件哈希或凭据。
