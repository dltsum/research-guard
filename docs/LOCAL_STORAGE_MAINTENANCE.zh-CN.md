# 本地存储维护

保留源码、结论和解释结果仍需使用的证据。普通清理不需要摘要清单、签名收据
或整仓库重测。

只删除本任务拥有的可丢弃文件，或用户授权的具体路径。递归删除或移动前核对
解析后的目标，尤其注意 Windows；不扩大到用户目录或整个工作区。仍被结果
引用的证据至少保留一份可读副本。

不常用资料可以归档。若原件仍有价值，丢弃前打开归档确认可以读取。同名或
同大小不能证明内容相同；确实依赖去重时比较内容即可，不要求生成校验码文件。

源码和依赖仍可获得时，构建结果、下载素材和安装副本可以重新生成。同目录
更新组件时保留用户添加的文件。只有可能影响行为的改动才运行相应检查，
清理可丢弃缓存不要求重新执行全部科研流程。
