# Local storage maintenance

Keep source, conclusions and evidence needed to interpret a result. Routine
cleanup needs no digest manifest, signed receipt or whole-repository retest.

Delete only task-owned disposable files or paths the user authorized. Check the
resolved target before recursive removal or movement, especially on Windows;
do not broaden cleanup to a user profile or workspace root. Keep one readable
copy of any evidence still cited by a result.

An archive can preserve cold material. Open it to confirm it is usable before
discarding an original that still matters. Equal names or sizes alone do not
establish identical contents; compare contents when duplicate removal depends
on that fact. No checksum file is required.

Build outputs, downloaded payloads and installed copies can be regenerated
when their source and dependencies remain available. Preserve user-created
files during an in-place component update. Run checks only for a change that
could affect behavior; cleaning an expendable cache does not require every
research workflow to be executed again.
