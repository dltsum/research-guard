# 2026-10-22 冗余操作复查

本轮继续检查实际调用路径，清理上轮仍残留的重复运行、文件摘要扫描和维护说明中的强制流程。修改前的基线为 `fd4019e`。测试按受影响范围各执行一次，只有失败、后续相关修改或明确验证重复行为时才复测。

安装交互还发现一个会诱导多余安装的状态描述：没有检查已有 Python 包时，安装器原来报告 `REQUIRED_NOT_INSTALLED`。现改为 `NOT_CHECKED`，不把“未探测”写成“缺失”，也不自动运行包探测或 pip。

首轮跨平台 CI 又发现安装器过度禁止祖先目录别名，连 macOS 系统 `/var` 链接也会拦截。已改为允许普通父目录别名，在解析后的目标内检查实际复制路径；目标本身为链接时的保护保留。Windows 测试改为比较实际文件身份，兼容同一目录的长名、短名和长路径前缀。

## 本轮验证

- 14 个公开 SkillOpt CLI 各调用一次，均退出 0，默认请求和实际执行均为一轮。合计 292 次测试执行，其中 291 次通过、1 次因 Windows 符号链接权限跳过；入口之间存在模块交叠，292 不是唯一测试数。P12 另完成 18 个真实优化 trial，未写回默认配置。
- 写作、图像、数学等 38 个受影响模块共覆盖 261 项：260 项执行通过，1 项 Windows 符号链接环境跳过。首次新 IO 观测器漏计 Windows 长路径别名，仅修观测器后单项复测通过。
- Skill 研究、迁移、组合与说明检查一次执行 55 项，全部通过，无跳过。新增真实 finalized 协议回归确认 handoff 只加载一次。
- 根端首批七组相关检查 56 项全部通过。后续按新增修改执行文档/复现/回放、学科状态、知识图谱和安装状态检查；实际复现命令运行一次、输出检查一次，无后台二进制摘要读取。新路径观测器的两个 Windows 别名失败仅重测失败项；一次错误 unittest 类选择未运行产品测试，修正选择后单项通过。原始记录保留。
- 新执行器还用真实子进程检查默认一次、显式多轮、非法次数不启动、空测试不报通过及失败输出保留。首次空测试断言兼容 Python 3.14 的返回码 5 后，只重测该项。

各组存在交叠，以上数字不相加为唯一测试总数。本轮没有重复运行此前的 953 项全项目离线套件。跨平台 CI 随本次推送在各目标系统执行；以提交的实际 checks 为准，不沿用上一提交的 CI 结果。

## 保留的有效行为

用户指定的参考写作三名真实审计、参考图每轮三名真实审计与所需多轮，以及七类交付仍保留。真实来源与论据对应、数值一致性、图像像素比较、编译和数学执行、独立数据切分仍实际检查。少量内容标识和图像重复检测指纹用于关联或比较，不要求用户复制摘要，也不作为安装、编辑或完成任务的验真步骤。
