# 作图工作流版本 0.7.4

## 0.7.4 的针对性修正

用户提供的问题截图须明确定位到实际交付图，并检查它与验收范围的重叠。内侧色带
通过，不能认证未测量的外侧倒角。检查完整相连边界、旧箭头头部占地以及邻层遮盖；
剩余填色干净不代表框边被完整保留。相同行箭头须测量最终像素，不能只看源码坐标。
用有意的恒色色带保留立体感，不把意外噪点改称渐变。

新增两个合成回归案例，复用既有像素检查器，展示外侧色带漏测和后层背景遮盖的失败
模式。它们是软件证据，不是全图批准。用户要求 PNG/PDF/PPTX 时，三种交付应来自
同一终版，并如实标明图片式 PPTX。完整分发包保持增量：压缩变化不得删文件或降低
图像保真度。下方历史案例继续保留其原始证据范围。
版本生命周期回归改为检查新渲染数值和旧导出的逐字节保留，替代对已删除的计划摘要
字段的过时依赖。

## 范围与价值

0.7.2 已沉淀参考图精确纯色修复、仅改变布局的单行改版流程。0.7.3 进一步纳入
任务关联代码示意图与用户要求的紧凑改版中的针对性经验。
它扩展 Research Guard，不是把项目替换成图像生成器。Skill 负责需求、工具选择、
审阅与证据；宿主提供图像生成和真实审阅智能体。确定性修复须有用户明确授权。

## 0.7.3 的针对性变更

仅在任务/代码 UI、过时内容清除或紧凑缩放时阅读
[任务忠实修复引用](../skills/academic-figure-guard/references/task-faithful-repair.md)：

- 各视图一致对应真实源/目标版本、路径、包含端点的行范围与原文片段。明确标注
  示意提案与回执；源码验证不是新的模型运行，也不是性能测量结果。
- 清除包括括号与抗锯齿边缘在内的完整旧文字占地，同时保护邻近图标。区分意外
  淡色光环与有意玻璃高光，包括窗框/标题栏接缝和畸形窗口控件。
- 重绘窗口装饰时保持图层顺序：按已知几何排除标题/箭头前景，或将其恢复到修复层
  之上，不遮盖穿越区域。恒色环形内嵌修复是局部选项，不是通用玻璃样式。
- 仅按用户要求紧凑化，保留可读文字、组件几何和任务含义。补充有用且缺失的任务
  内容，而非重复装饰性 UI。
- 最终重采样后重新映射并检查遮罩/排除区、框体和锚点；重跑当前像素检查及最终
  显示尺寸审阅。不得沿用旧 PASS 数量。局部填色结果不等于全图或印刷可读性认证。

触发本次经验的用户要求是把一张图的高度从 1448 降到 1378 像素（约 4.83%）。
这是该案例的具体请求，不是默认比例、宽高比变形强制规则，也不代表此次 Skill
更新已绘制或认可该图。新增行为测试复用既有像素/几何检查器；本次不修改图像
渲染器、打包实现或无关能力。

## 工作流程

1. 阅读原稿和参考图，登记术语、必需组件和信息流。
2. 明确不同参考图贡献的设计元素；未另行要求时默认英文。
3. 保留丰富 UI 组件，先对齐面板和端口，再减少箭头转折。
4. 使用获授权的绘制方式，保留可编辑组件与终图。
5. 先登记预期纯色区域和排除范围，再检查颜色。
6. 对每个有效像素检查声明 RGBA，并执行缺陷负向对照。
7. 由真实智能体对实际终图进行信息、风格、细节审阅。
8. 修复、复扫、复查，保留失败版本而非覆盖失败结论。交付可用文件、脚本、记录与限制。

详见[修复与改版指南](../skills/academic-figure-guard/references/repair-and-layout-playbook.md)
与[像素流程](FIGURE_FLAT_FILL_AUDIT.zh-CN.md)。

## 0.7.2 的两个历史真实案例证明了什么

配套提交包保存实际产物和审阅记录。这是同一科研图上的两个连续输入任务，不是两个
无关领域，也不是统计意义的质量基准测试。

| 案例 | 要求 | 最终范围内证据 | 重要审阅修正 |
|---|---|---|---|
| 精确修复 | 保留认可的设计，消除噪点和不均匀填色 | 4,826,778 个有效像素；RGBA 超限为零 | 恢复摘要条与堆叠文档图标 |
| 单行改版 | 2×2 改成 1×4，不改变含义 | 7,600,434 个有效像素；RGBA 超限为零 | 恢复四个端点角色标签和可见箭头头部 |

两图总像素分别为 6,292,656 和 9,125,400。文字、描边及固定边缘带明确排除并计数；
不是整张图都应纯色。每个案例均检出了四个负向对照。审阅记录只适用于对应产物，
不能推广为以后所有生成结果均通过。

## 复现与安装

需要 Python 3.11+。通用矩形像素检查器只需 Pillow；两个场景遮罩脚本还需 NumPy。
重新绘制历史案例需要 Windows Times New Roman；检查已交付的 PNG/遮罩不依赖字体。

在仓库目录运行：

```sh
python scripts/component_install.py --components figures --target ../research-guard-figures
python -m unittest discover -s tests -p "test_p31_flat_fill_evidence.py" -v
python -m unittest discover -s tests -p "test_figure_connector_turns.py" -v
python -m unittest discover -s tests -p "test_figure_repair_boundaries.py" -v
```

需要安装所选依赖时再加 `--install-python-deps`。虚拟环境、MCP 注册和原位更新见
[安装提示](../INSTALL_PROMPT.md)。源码 ZIP 不包含内置运行时。
