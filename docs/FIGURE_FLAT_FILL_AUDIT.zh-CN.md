# 作图填色逐像素检查

## 声明所有预期表面

清点所有应当纯色的背景/卡片。只有实际设计要求支持时，才把参考插画、照片、渐变、
阴影单列为有意效果；生成结果已有某效果不等于获准使用。保留丰富 UI 与组件绘制，
不能为背景检查通过而把整图扁平化。

在 `flat_regions` 声明内部 `bbox` 矩形，不规则内部拆开。用 `exclude_boxes` 和
`exclusion_reason` 排除已知文字、图标、描边、抗锯齿及阴影；全候选图坐标须在该区域内。
不能只挑干净角落、排除缺陷，或把几块小区域说成整图覆盖。对照图片审阅完整清单与
排除范围；检查器不能推断艺术意图或发现清单中遗漏的表面。

对于用户提供的问题截图，先把可见缺陷表面定位到实际交付图，再计算与验收范围的
重叠。其他位置的 PASS 不能证明未覆盖的问题已解决。保留相同坐标的修复前后局部图，
明确报告覆盖缺口。分层修复还要检查完整组件边界与非预期遮盖，不能只测剩余表面内部：
后一层背景可能截断前一层框边，而所有剩余填色仍然通过。

## 执行像素扫描

在检查颜色数值之前建立区域清单与排除几何。对于源场景生成的遮罩，即使表面被完全
覆盖、或者细描边没有可测试内部，也保留其区域 ID 和预期 RGBA，并明确标为排除，
不能写成已测 PASS。把像素划分为不重复的有效像素、有理由的排除像素和未归属像素；
只有未归属像素为零才可声称完整声明覆盖。矩形重叠时区域总数可能重复计数，不能把
区域计数之和称为整图不重复像素数。

```json
{"flat_regions":[{"id":"card-interior","bbox":[20,20,180,100],
  "max_channel_range":0,"exclude_boxes":[[40,40,100,60]],
  "exclusion_reason":"Known text foreground; border lies outside bbox."}]}
```

```sh
python scripts/figure_pixel_audit.py reference.png final.png --output audit \
  --regions regions.json --geometry geometry.json --require-flat-fills
```

遍历每个未排除的像素，包含透明度。报告包含精确检查/排除数量、RGBA 最小值、最大值、
范围、超限数量、包围框和首批坐标。`max_channel_range=0` 要求声明内部的各通道完全一致。
更大的整数容差必须来自设计要求，不能看到失败后为了掩盖问题而调大。
可选 `expected_rgba` 还检查指定颜色。未指定时，各通道最小值为允许区间起点；
它们不是理想颜色，也未必是一个实际出现的联合 RGBA 像素。超限数量/位置针对该比较，
不能自动解释成每个伪影像素的标签。
精确修色必须提供 `expected_rgba`：整块颜色都错但均匀，仍可能通过单纯的均匀性检查。
标准矩形 CLI 不会自动推导几何遮罩。不规则区域需要随结果提供源场景检查器，或者
显式拆分区域，不能按像素当前颜色选择待检像素。

缺范围是 `NOT_RUN`，不均匀是 `FAIL`，只有实际完成并成功才是 `PASS`。
`--require-flat-fills` 在 FAIL 或 NOT_RUN 时退出码为 2。旧式仅比较调用仍可出报告，
但不能用来批准填色。参考与候选尺寸不同不影响候选自身填色检查；SIZE_MISMATCH 是
另一项比较结果。

## 修正并重新检查

失败时保留报告并指出区域/坐标。使用获授权的图像/源文件流程修正相关填色，保留文字、
边框、图标和有意 UI 细节。按相同期望扫描实际修正后的终图，同时检查受影响的语义/
风格回退。缺陷存在且可获授权修正时继续；若受阻，报告具体未满足要求。不能把失败
改称可接受，也不能把检查器修好了说成图已修好。

参考图审计从实际终图像素和声明几何范围重算填色指标。即使所有审阅布尔都为真，
缺失/失败的检查也阻止 PASS，虚假指标会被拒绝。状态查询只读已有结果；旧图应显式
重新评估，无需文件摘要或重新登记仪式。

## 证据边界

执行单步 RGB 扰动、仅透明度扰动、整块均匀但颜色错误三个负向对照，保留检测位置与
数量。修改排除区像素只能在另行声明的全导出比较中测试，它本来就不在纯色保证范围内。
确定性渲染重放检查的是导出一致性，不是独立的语义或设计正确性证明。

修复后在实际终图上按同一覆盖/颜色约定重新扫描，并审阅保留的图标、堆叠文档、摘要条、
端口及标签。失败审阅与后续复查分别保留，不能复用旧候选图的批准，也不能为消除纹理
而删除丰富的 UI 设计。

局部 PASS 不认证未列出的表面、有意插画、语义、风格或印刷可读性。像素测量补充
真实看图，不能取代它。单元夹具测试的是软件，不是原生智能体质量。保留真实失败与
有意义的正向对照。
