# Support

Use [GitHub Discussions](https://github.com/dltsum/research-guard/discussions)
for usage questions once discussions are enabled. Use a
[bug report](https://github.com/dltsum/research-guard/issues/new?template=bug.yml)
for reproducible failures and a
[capability proposal](https://github.com/dltsum/research-guard/issues/new?template=feature.yml)
for new research fields, sources, or modules.

Do not post credentials, private papers, provider responses, local paths,
unreleased data, or complete proprietary database exports. Use synthetic
reproductions and hashes where possible. Security issues must follow
[SECURITY.md](SECURITY.md), not a public issue.

The project provides best-effort community support for the latest release.
Research Guard does not provide scholarly, legal, medical, publication, or
venue-acceptance guarantees. A PASS is bounded to its recorded inputs and
evidence.
