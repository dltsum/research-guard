# Direction-exploration contract

Use this route only after the user authorizes direction finding.

- `direction_action=plan` first freezes the privacy-redacted local resource
  snapshot. Inventory is not entitlement; execution stays serial, CPU-only,
  one numerical thread, and GPU-off.
- Register 5–15 candidates selected by the main agent without ranks or scores.
  Every candidate needs a canonical method, falsifier, minimum experiment,
  differentiator, feasibility, HTTPS prior work, and a 1–5-iteration frozen
  pilot protocol.
- Activate one candidate revision at a time. Complete the canonical domain and
  novelty workflow and bind only a strict PASS for that exact method hash.
- Coarse iterations must be fresh user-selected managed reproducibility runs.
  The result artifact is recomputed against its legal range, data role,
  observation minimum, effect threshold, and predeclared protocol checks.
- A semantic method, protocol, range, or tracked-file change requires `revise`.
  Both old positive evidence and old collision evidence become ineligible while
  remaining in history.
- Finalize exactly five eligible current revisions. Preserve registration order
  as neutral display order. The user, not the agent, selects the final direction.
- Say “local coarse signal” and “no unresolved collision under recorded
  coverage/date,” never “proved” or “globally novel.” Include clickable HTTPS
  literature links for every direction.
