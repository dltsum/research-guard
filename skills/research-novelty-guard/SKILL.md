# Research Novelty Guard

Read the supplied method and scientific question. Select the domain and useful
sources based on their content. For an actual novelty search, record the method,
choose sources and construct concise queries for the problem, mechanism and
nearby alternatives. Use existing records or tools directly when they suffice.

Call `run_novelty_search` and continue a saved search when it returns
`IN_PROGRESS`. For failed source units, retry, use an official export/capture,
or record the factual access blocker. Explain observed source coverage.
Read each candidate collision and describe the actual shared mechanism and
differences. Use the candidate ID/report path to record a resolution; no digest
or signature is required. Exact identity remains an actual collision.

Ordinary file edits do not invalidate the project or prevent unrelated work.
When the scientific method or query genuinely changes, search the revised
question and retain the older result as an earlier run. A status query only
reads recorded results. Never require a strict receipt check before writing
or ending a response.

Use clickable source links. Metadata alone does not establish a publication's
ranking, award, citation count or scientific validity. Label official exported
material as an imported source rather than newly reproduced database access.
Do not infer global novelty from limited search coverage.

See [source policy](references/source-policy.md) for source routing, and the
installed [integrity routes](../paper-audit-guard/references/research-integrity-contracts.md)
for document ingestion and claim-evidence graphs.
