# Reference-guided writing

Read the user's experiment records and the reference paper. Preserve the existing
outline and requested revision scope. Compare research object, method and content
separately. For recent-paper selection, use the user's date threshold and any one
requested qualification route: CAS zone 1 with more than ten citations; CCF B or A
with best-paper/best-student-paper nomination or higher; or CCF A with oral or higher.
Support qualifications with dated primary links. Record unknown qualifications
as unknown and keep researching; do not invent them or treat venue prestige as proof.

Follow the reference's reasoning while adapting it to the user's work. Check
section, subsection, paragraph, sentence, word, long-range correspondence, wording
and total length. Preserve the reference figures/tables' functions with supported
counterparts. Explain whole-paper consistency actions without changing the outline.
Remove defensive presentation, while retaining real limitations and uncertainty.

Deliver the requested seven classes:

1. Revised manuscript.
2. PDF compiled with the relevant official paper kit.
3. Experiments or explanations still needed to support the reference's logic.
4. Reference logic analysis.
5. Detailed word/sentence/paragraph logic comparison.
6. A runnable structural logic-check script and its input.
7. When mathematics and a local Lean environment are present, one complete,
   actually compiled Lean file without unexplained parameters or unproved shortcuts.

Use `reference_writing_action=plan/register_reference/submit/audit/status` when the
structured workflow helps. Provide ordinary file paths; checksums and prior receipts
are not required. A compiler log can be retained as useful execution evidence, but
the absence of a specially formatted receipt must not prevent reading or drafting.
PDF delivery must be a real readable PDF. Run Lean on the actual file when claiming
compilation; a historical receipt does not replace execution.

Obtain three actual reviews: logic matching, defensive writing, and scientific
adequacy. Retain their dialogues, findings, and corrections. Reviewers inspect the
delivered text and reference; they do not need to repeat file digests. The logic
script checks structural coverage, relations, protected information and length;
semantic/scientific judgment remains part of the actual reviews. Show missing
experiments clearly instead of filling gaps with fabricated results.

Files may be edited and reviewed again in the same workflow. Recheck affected
content as useful; do not force replanning, signatures, or repeated validation.
