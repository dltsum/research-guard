# Writing review guidance

Work from the current manuscript. Preserve factual meaning, uncertainty, numbers,
citations, formulas and real limitations. Remove unnecessary hedging, imagined
critics, disclaimer-first framing and process narration. Translation should retain
technical terminology and factual invariants. Do not conceal AI usage or invent
scientific evidence.

Use actual official venue/year/track/stage material when formatting depends on it.
The venue helper can supply context, but a receipt is not a prerequisite for ordinary
drafting or editing. State unknown formatting requirements while doing useful work.

Analyze the current text, fix findings, and report any unresolved substantive issues.
Limitation and ethics suggestions are review guidance, not mandatory forms requiring
the user to approve each sentence. A normal file edit can be analyzed directly.
No checksums, signed receipts, or full workflow restart are required.

Rhetorical cards describe reusable reasoning moves with primary source locators;
reuse the moves rather than copying prose. AI-reviewer comparisons should use
identified runs, a common meaningful rubric, actual scores and clear scope. Do not
require prompt/input/review digests or infer human acceptance from model scores.
