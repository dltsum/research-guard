# Macro-first paper-spine contract

This reference describes the executable `language_assist` `spine_action`
subroute. It complements, rather than replaces, the venue and novelty owners.

## Formation order

1. Record the local observation and the explicitly selected domain scope.
2. Ask what broader scientific problem the observation makes visible.
3. State one unifying method, mechanism, or invariant that can be tested in
   more than the named case.
4. Register at least two distinct cross-context predictions and falsifiers.
5. Bind a source-linked evidence plan and produce five unranked titles spanning
   macro, meso, and local levels.
6. Run the canonical collision search for the exact method revision and bind
   its strict receipt with `spine_action=bind_collision`.

## What the contract prevents

- A nearby paper is not a reason to retreat to an isolated feature question.
- “No collision found” is not global novelty proof.
- A title level is not a scientific ranking; the user chooses the final frame.
- A broad frame cannot outrun its registered contexts, source locators, or
  falsifiers.

The main agent supplies the semantic synthesis. The local module checks the
shape, source links, title-level diversity, hash binding, and current novelty
receipt; it does not classify the domain or invent an automatic contribution.
